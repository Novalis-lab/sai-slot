# サイ⚪︎スロット

予算を入れて「スロットを回す」を押すと、サイ○リヤで予算内に食べられるメニューの組み合わせがランダムで出てくる **非公式** Webアプリです。

公開URL：https://novalis-lab.github.io/sai-slot/

## ファイルの役割

| ファイル | 役割 | さわる頻度 |
|---|---|---|
| `menu-data.js` | メニュー名・価格・カテゴリのデータ | **季節ごとに更新** |
| `index.html` | 画面の骨組み | たまに |
| `style.css` | 色やレイアウト | たまに |
| `app.js` | スロットの仕組み | ほぼさわらない |

## メニューの更新方法

`menu-data.js` だけを開いて直します。

- **値段が変わった** → その行の `price:` の数字を書きかえる
- **新メニューが出た** → 同じカテゴリの行をコピーして、名前・番号・値段を書きかえる
- **メニューがなくなった** → その行を消す（または `hide: true` をつけて一時的に隠す）
- **メニュー版の表示** → ファイル上部の `MENU_VERSION` を書きかえる

書きかえたら、ブラウザで `index.html` を開いて動くか確認してから GitHub にアップロードします。

## 広告を入れるとき

`index.html` の `<aside class="ad-slot">` の中に、広告サービス（Google AdSense など）のコードを貼り付けます。
「広告スペース」の文字（`<span class="ad-placeholder">…</span>`）は消してください。

## 出典

価格・メニュー番号はサイ○リヤ公式メニューブック「グランドメニュー 2026.10 A」をもとにしています。
店舗や時期によって異なる場合があります。
